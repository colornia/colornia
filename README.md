## About

My work sits between mechanical engineering, embedded systems, and AI. I care about systems that can act, recover from failure, and produce evidence that can be checked—not just outputs that sound plausible.

**Current interests:** intelligent machines, agent workflows, engineering evaluation, and learning-based optimization.

**[OpenSquad](https://github.com/colornia/opensquad)** is an AI teammate that joins a Minecraft server as another player. It combines explicit action flows, state and memory management, interruption handling, privacy controls, and automated behavioral checks.

**[VulnGym contributions](https://github.com/Tencent/VulnGym)** focus on verifiable evaluation data for vulnerability-hunting agents. [PR #36](https://github.com/Tencent/VulnGym/pull/36) validated **408 entries / 2,889 annotation nodes**, producing **13 automatic fixes** and **26 human-review cases**. [PR #62](https://github.com/Tencent/VulnGym/pull/62) delivered an idempotent generator and an independent verifier with **6 checks**.

## Resume Highlights

- **Mechanical engineering background:** undergraduate academic rank **3/155 (Top 1.9%)**, with First-Class Academic and TCL Huameng scholarships.
- **Biomimetic flapping-wing robot:** led embedded control and transmission design using Arduino/STM32, PWM-driven micro servos, and cam/gear mechanisms; received a **National Third Prize** and a **Provincial First Prize**.
- **Autonomous solar vehicle:** designed a variable-curvature cam steering mechanism to follow a complex track without electronic steering or tracking modules; received a **National Gold Award** and a **Provincial Grand Prize**.
- **CVRP neural solver:** implemented an Attention Encoder–Decoder with POMO rollout in PyTorch; reached **100% feasible solutions on 1,500 instances**, approximately **200× OR-Tools inference speed**, and an average cost gap of about **+1.15%**.

## Current Focus

I am exploring clearer role separation and multi-agent coordination in OpenSquad, agent workflows that connect language-model reasoning with code and physical constraints, and evaluation methods based on reproducible inputs, automated checks, and explicit failure cases.
