## About

My work sits between mechanical engineering, embedded systems, and AI. I care about systems that can act, recover from failure, and produce evidence that can be checked—not just outputs that sound plausible.

**Current interests:** intelligent machines, agent workflows, engineering evaluation, and learning-based optimization.

## Featured Work

### [OpenSquad](https://github.com/colornia/opensquad)

An AI teammate that joins a Minecraft server as another player and completes tasks through in-game chat. The project combines explicit action flows, state and memory management, interruption handling, privacy controls, and automated checks for collection, delivery, and combat-related behavior.

### [VulnGym Contributions](https://github.com/Tencent/VulnGym)

Open-source work on a real-world benchmark for vulnerability-hunting agents.

- [PR #36](https://github.com/Tencent/VulnGym/pull/36): validated **408 entries / 2,889 annotation nodes**, producing **13 automatic fixes** and **26 human-review cases** with traceable evidence.
- [PR #62](https://github.com/Tencent/VulnGym/pull/62): delivered an idempotent data generator and an independent verifier with **6 checks** for configuration vulnerabilities.
